管理界面、数据与同步

主题皮肤

皮肤选择保存在当前设备；手机和电脑可以各自选择。

界面版本

只影响当前设备。手机版纵向排列，电脑版优先使用宽屏布局；窄屏仍会自动适配。

数据备份

你的所有数据都存在当前设备的浏览器里；开启同步后，云端也会保存一份。
换手机、清理浏览器数据前，记得先导出备份。

简单口令锁

用于防止身边人随手翻看，不是高强度加密。口令只保存在当前设备，不参与同步和备份。

Grok 实时额度

安装 Grok 周额度同步扩展后，工作台会显示你的每周订阅限额、使用比例和重置时间。扩展不会读取聊天内容或 API Key。

双端同步

开启后手机和电脑登同一个账号，记的东西自动对齐。
数据会在你的设备和云端各存一份，本地那份始终在，断网照样能记。
云端那份是明文的——只有知道你密码的人能读，但平台运维理论上能看到。
密码忘了就进不去了，没有找回功能。

建议先导出一份备份再开——万一以后忘了密码，本地这份还在。
