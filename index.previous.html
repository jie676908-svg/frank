💾 数据备份

你的数据默认保存在当前设备的浏览器中。
换手机、清理浏览器数据前，记得先导出备份。

🔄 双端同步

开启后手机和电脑登同一个账号，记的东西自动对齐。
数据会在你的设备和云端各存一份，本地那份始终在，断网照样能记。
云端只保存由当前设备加密后的数据，解密在你的浏览器中完成。
密码忘了就进不去了，没有找回功能。

建议先导出一份备份再开——万一以后忘了密码，本地这份还在。

🧠 API 额度

API Key 只保存在当前设备，不进入备份和云同步。查询时仅直接发送到 DeepSeek 或 MiniMax 官方接口。

🔒 简单口令锁

用于防止身边人随手翻看，不是高强度加密。口令只保存在当前设备，不参与同步和备份。

🎨 主题皮肤

皮肤选择保存在当前设备；手机和电脑可以各自选择。

🏛️ 背景场景

场景会以低透明度和虚化方式铺在整个工作台后方，不影响阅读。

🎭 左侧栏定制

侧栏风格和名称只保存在当前设备，电脑和手机可以分别设置。

🖥️ 界面版本
